# Lógica de Programação em JavaScript

Exercícios de lógica de programação em **JavaScript**, com estruturas de decisão (`if / else if`), funções e template strings.

## Arquivos

| Arquivo | O que faz |
| :--- | :--- |
| `index.js` | Classifica o nível de um herói a partir da quantidade de XP. |
| `desafio02.js` | Calcula o saldo de vitórias (vitórias − derrotas) e define o elo do herói pelo número de vitórias, usando funções. |

## Níveis por XP (`index.js`)

| XP | Nível |
| :--- | :--- |
| menos de 1000 | Ferro |
| de 1000 a 1999 | Bronze |
| de 2000 a 2999 | Ouro |
| de 3000 a 3999 | Platina |
| de 4000 a 4999 | Ascendente |
| de 5000 a 5999 | Imortal |
| 6000 ou mais | Radiante |

## Elos por vitórias (`desafio02.js`)

| Vitórias | Elo |
| :--- | :--- |
| até 10 | Ferro |
| de 11 a 20 | Bronze |
| de 21 a 50 | Prata |
| de 51 a 80 | Ouro |
| de 81 a 90 | Diamante |
| de 91 a 100 | Lendário |
| acima de 100 | Imortal |

## Como executar

É preciso ter o [Node.js](https://nodejs.org/) instalado.

```bash
git clone https://github.com/OpedroPrataDEV/Logica_Programacao.git
cd Logica_Programacao
node index.js
node desafio02.js
```
